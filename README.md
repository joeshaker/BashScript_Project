# BashScript_Project

A Bash scripting project designed to automate data processing and demonstrate Linux command-line skills using shell scripting and text-processing utilities.

## 🚀 Project Overview

This project demonstrates how to build a Bash script that processes data files, organizes the results, and handles execution logs.

It uses common Linux utilities such as `awk`, `sort`, `uniq`, `wc`, and `cut` to perform data-processing operations.

## 🛠️ Technologies & Tools

- **Bash Scripting** – Automating tasks using shell scripts.
- **Linux / Unix Commands** – Working with files and directories.
- **AWK** – Text and data processing.
- **Sort & Uniq** – Sorting data and removing duplicates.
- **WC & Cut** – Counting and extracting data.
- **Git & GitHub** – Version control.

## 📋 Prerequisites

Before running the project, make sure you have:

- Git installed.
- Bash shell (Linux, macOS, or Git Bash on Windows).
- Required command-line utilities:
  - `awk`
  - `sort`
  - `uniq`
  - `wc`
  - `cut`

## ⚙️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/joeshaker/BashScript_Project.git
```

### 2. Navigate to the Project Directory

```bash
cd BashScript_Project
```

### 3. Give the Script Execution Permission

```bash
chmod +x project_bash_script.sh
```

### 4. Run the Bash Script

```bash
./project_bash_script.sh
```

**Note:** Run the script from the project root directory to ensure that relative file paths work correctly.
